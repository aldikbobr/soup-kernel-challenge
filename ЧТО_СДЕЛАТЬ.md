# Что требуется от вас (Decentrathon 6.0, трек 1 — Soup Kernel Challenge)

**Дедлайн: 31 октября 2026, 23:59 по Астане.** Сдача на сайте хакатона:
https://edu.astanahub.com/hackathons/82b11400-bee4-4d30-9223-5515527d365b → вкладка «Треки» → «Сдать решение».

Код решения уже готов (папка `solution/`), проверен тестами на CPU. Осталось измерить его на
видеокарте Kaggle T4, вписать цифры и сдать.

## 1. Продолжить работу с Claude Code (один раз)
1. Установите Claude Code (https://claude.com/claude-code) или откройте приложение Claude → Code.
2. Склонируйте этот репозиторий и откройте его в Claude Code:
   ```
   git clone https://github.com/aldikbobr/soup-kernel-challenge.git
   cd soup-kernel-challenge
   claude
   ```
3. Напишите: **«прочитай CLAUDE.md и ЧТО_СДЕЛАТЬ.md и продолжай»**. Там вся история и план.

## 2. Kaggle (без этого нет замеров)
1. Зайдите на https://www.kaggle.com (кнопка «Sign in with Google»).
2. Подтвердите телефон: аватар → **Settings → Phone Verification**. Без этого Kaggle не даёт GPU.
3. Create → New Notebook → File → **Import Notebook** → файл `templates/kaggle_notebook.ipynb`
   из этого репозитория.
4. Справа: **Accelerator: GPU T4 x2**, **Internet: On**.
5. В первой ячейке: `REPO_URL = "https://github.com/aldikbobr/soup-kernel-challenge.git"`.
6. **Run All** (~15 минут). Скопируйте вывод трёх последних ячеек (таблица PASS/FAIL и строка
   `speedup ... memory ...`) и отдайте Claude — он исправит, если что-то не так.
7. Повторять 6, пока все 10 проверок не станут PASS.

## 3. Сдача (31 октября, лучше до 20:00 по Астане)
1. В Kaggle: `COMMIT` в первой ячейке = последний коммит, **Save Version → Save & Run All**,
   ноутбук сделать **Public**. Ссылку на эту версию — Claude, он впишет её в README и SUBMISSION.md.
2. Видео до 3 минут (сценарий подготовит Claude): экран + голос, что ускорили и какие цифры.
   Загрузить на YouTube (по ссылке) или Google Drive с доступом «всем по ссылке».
3. Презентация (сделает Claude) — ссылка.
4. На сайте хакатона: «Сдать решение» → ссылка на репозиторий, Kaggle, видео, презентацию.
5. Перед сдачей удалить из репозитория `CLAUDE.md` и этот файл.

## Правила, которые важно не нарушить
- Капитан команды должен быть **старше 18 лет**.
- Один результат от команды, до 4 человек.
- Репозиторий и Kaggle-ноутбук к дедлайну должны быть **открыты** для жюри.
